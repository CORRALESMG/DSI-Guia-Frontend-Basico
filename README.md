## Descripción
Página web personal creada con HTML y CSS para identificar la estructura
básica del frontend.

## Contenido de la página
- Encabezado principal (`<h1>`) y subtítulo (`<h3>`)
- Párrafo de presentación personal (`<p>`)
- Lista de habilidades (`<ul>`, `<li>`)
- Imagen (`<img>`)
- Enlaces a sitios favoritos (`<a>`)

## Estructura del proyecto
- `index.html` → estructura de la página (HTML)
- `Style.css` → diseño de la página (CSS)
- `Gatito.jpg` → imagen de la página

## Etiquetas utilizadas
`<html>`, `<head>`, `<body>`, `<h1>`, `<h2>`, `<h3>`, `<p>`, `<ul>`, `<li>`, `<img>`, `<a>`, `<link>`, `<div>`
